# MML Studio 言語リファレンス（実装済みの構文のみ）

対象: Phase 0〜4 の実装。PPQ は 480（四分音符 = 480 tick）。英字コマンドは大文字・小文字を区別しない。

| 記述 | 意味 | 範囲・初期値 |
|---|---|---|
| `c d e f g a b` | 音符 | 結果の MIDI 音高 0〜127 |
| `+` `#` / `-` | 直前の音名を半音上げ／下げ | 1個まで |
| `r` | 休符 | |
| `oN` | オクターブ | 0〜9、初期値 4（`o4c` = 60） |
| `>` / `<` | オクターブ +1 / −1 | 結果 0〜9 |
| `lN` / `lN.` | 省略時の音長 | N = 1,2,4,8,16,32,64、初期値 4 |
| `cN` / `cN.` | 個別の音長・付点 | 付点は1個まで（×1.5） |
| `c4^8` | 音長加算（1音） | `^` の後に音長必須、連続可 |
| `c4&c4` | 同音高タイ（1音） | 異なる音高・休符・トラック切替をまたぐとエラー |
| `nN` | MIDI ノート番号 | 0〜127、音長は `l` に従う |
| `tN` / `Tempo(N)` | テンポ（楽曲全体） | 20〜300、初期値 120 |
| `vN` | ベロシティ | 0〜127、初期値 100（0 は無音） |
| `qN` | ゲート率 % | 0〜100、初期値 90（0 は無音） |
| `@N` | GM 音色 | 1〜128、初期値 1（CH10 では不可） |
| `TR(N)` / `Track(N)` / `TR=N` | トラック切替 | 0〜32、初期値 1。TR(0) はテンポ専用 |
| `CH(N)` / `Channel(N)` / `CH=N` | MIDI チャンネル | 1〜16（10 = GM ドラム） |
| `'ceg'4` / `'n60 n64'%300` | 和音（同時発音、音長・v・q を共有） | 2音以上、同音高の重複不可。`<` `>` は和音内だけ有効 |
| `Sub{ … }` | 内部を演奏後、演奏位置（cursor）だけ戻す | 入れ子8階層。中で `TR` `CH` `t` `Tempo` `TempoUS` `Time` は不可 |
| `Time(M:B:S)` | 演奏位置を絶対指定 | M≥1、B=1〜4、S=0〜479。tick = ((M−1)×4+(B−1))×480+S（4/4 固定座標） |
| `c%N` `r%N` `n60%N` `l%N` | tick 単位の音長 | 1〜2,000,000。分母式・付点と併用不可。`^` の後は分母式のみ |
| `q%N` | 発音長を tick で指定 | 0〜2,000,000（0 は無音）。`qN` と切り替え |
| `CC(C,V)` | コントロールチェンジ | 0〜127。時間は進まない |
| `PB(N)` | ピッチベンド | −8192〜8191（中央 0）。時間は進まない |
| `TempoUS(N)` | テンポ（μs/4分音符、そのまま SMF に書く） | 1〜16,777,215 |
| `// …` / `/* … */` | コメント | 入れ子不可 |

## 規則

- 区切り: 空白・タブ・改行・`;`。音長・付点・臨時記号・数値は直前のコマンドに**空白なしで**続ける。
- 複数文字コマンドは直後に `(`（`TR`/`CH` は `=` も可）が続くときだけ認識する（`cc4` は C 音 2 つ）。
- 発音長 `gate = round(duration × q / 100)`（q > 0 なら最低 1 tick）。タイ・`^` で連結した音は最初の `v`/`q` を使い、合計の長さに対して1回だけ計算する。
- トラックごとに時刻・オクターブ・音長・ベロシティ・ゲート・チャンネルを保持し、切り替えて戻ると復元する。
- 初期チャンネル: TR(1〜9) → 1〜9、TR(10〜15) → 11〜16、TR(16〜32) は `CH` 必須。
- `CH` は最初の音符・`@` より前のみ。異なるトラックで同じチャンネルは使えない。
- テンポは楽曲全体で共通。同じ tick に異なるテンポを指定するとエラー（同じ値は統合）。テンポ指定が無ければ 120。
- 同じチャンネル・同じ音高のノートが時間的に重なるとエラー。
- 上限: 2 MiB、音符 100,000、演奏トラック 32、曲長 2,000,000 tick。
- `TR(0)` で使えるのは `t` / `Tempo` / `TempoUS` / `Time` だけ。`TR(0) Time(2:1:0) Tempo(90)` で曲の途中にテンポを置ける（TR(0) に戻っても位置は保持）。
- `t` と `TempoUS` が同じ tick で異なる値を指定するとエラー（μs 値で比較）。
- 同じ tick の SMF 出力順は Note Off → CC/PB/Program（ソース順）→ Note On。
- 未対応（エラー）: `[ ]` ループ、`{ }` 連符、マクロ、変数、ストトン。
